# DroneEbla

Стратегия в реальном времени о современной войне на истощение: экономика, дроны и ПВО. Вид сверху на реальную карту Украины и запада России (до Татарстана и Санкт-Петербурга), полный туман войны, сетевая игра на двоих через Radmin VPN.

Дизайн и все игровые правила описаны в [docs/GDD.md](docs/GDD.md).

## Запуск

1. Скачайте `release/DroneEbla.exe` (или свежую сборку из GitHub Actions → `DroneEbla-windows`).
2. Положите файл в отдельную папку и запустите. Ничего устанавливать не нужно: ни Python, ни библиотеки.
3. При первом запуске рядом с игрой появятся папки `data` (все игровые цифры в JSON) и `saves` (сохранения).

## Одиночная игра

«Одиночная игра (против ИИ)» → «Начать»: вы выбираете сторону (Россия или Украина), противоположной управляет компьютер. ИИ видит только то, что видит его разведка, и делает те же приказы, что и человек; его настройки лежат в `data/ai.json` (`smart: false` у стороны включает прежнего простого бота). Сохранение (F5) работает; загрузить партию можно кнопкой «без сети».

## Сетевая игра до 6 игроков через Radmin VPN

До 3 игроков на сторону (составы могут быть неравными: 3 на 2, 3 на 1 и т. д.).

1. Все заходят в одну сеть Radmin VPN.
2. **Хост**: «Создать сетевую игру» → выбрать сторону → «Создать». Игра покажет IP-адреса; остальным нужен адрес Radmin (обычно `26.x.x.x`). Если Windows спросит про брандмауэр — разрешите доступ (порт 27015/TCP).
3. **Остальные игроки**: «Подключиться к игре» → ввести IP хоста → «Подключиться». В лобби каждый сам выбирает сторону (до 3 мест на сторону).
4. Хост нажимает «Начать» (нужен хотя бы один игрок за каждую сторону). Игроки одной стороны делят казну, ресурсы, разведку и карту; приказы может отдавать любой из них. **Скоростью и паузой управляет только хост.**
5. Если игрок отключился, его место освобождается и игра идёт дальше; он может вернуться в любое свободное место (даже в середине партии). Если за сторону не осталось ни одного игрока, игра встаёт на паузу.
6. Сохранять может хост (кнопка «Сохранить» или F5); загрузить партию — «Загрузить сохранение (хост)», после чего игроки подключаются заново и снова выбирают стороны.

Папки `data` и версия игры у всех игроков должны совпадать, иначе подключение будет отклонено.

## Управление

| Действие | Как |
|---|---|
| Выбрать объект | ЛКМ |
| Сдвиг карты | перетаскивание ЛКМ по пустому месту, средняя кнопка, WASD или стрелки |
| Масштаб | колесо, `+` / `−` |
| Марш выбранного юнита | ПКМ по своей территории |
| Пауза / скорость | Пробел / `[` и `]` (или цифры numpad 1–5) |
| Группы | Ctrl+1…9 запоминает выбранный объект (Ctrl+Shift+цифра добавляет), 1…9 по кругу выбирает члена группы и переходит к нему |
| Пуск | выберите пусковую → `F` открывает планирование, повторное `F` — пуск |
| Полный экран | F11 или Alt+Enter |
| Оверлей быстродействия (FPS, память, видеопамять) | F3 |
| Масштаб интерфейса | Ctrl+«+» / Ctrl+«−», Ctrl+0 — авто |
| Меню партии (настройки, сохранение, выход) | Esc, когда ничего не выбрано, или кнопка «Меню» |
| Сохранить (хост) | F5 |
| Отмена режима | Esc или ПКМ |
| Найти юнит или источник пуска | вкладка «Арсенал»: клик по строке (например «Бук-М1») по кругу выбирает следующий, камера переходит к нему |

**Удар**: выберите пусковую, площадку БПЛА, аэродром или базу флота → кнопка «Удар: …» → щелчками задайте точки маршрута в обход ПВО, последняя точка — цель → количество и задержка → «Пуск!».

## Сборка из исходников

Нужен Go 1.24+ (нужная версия тулчейна скачается автоматически).

```bash
# Windows .exe (кросс-компиляция с любой ОС, без cgo)
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-H windowsgui -s -w" -o DroneEbla.exe ./cmd/droneebla

# Тесты симуляции и сети
go test ./internal/...
```

Карта уже собрана (`internal/world/map.bin`). Пересобрать её из данных Natural Earth можно так:

```bash
go run ./cmd/mapbake -ne <папка с ne_10m_*.geojson>
```

## Структура

```
cmd/droneebla      игра
cmd/mapbake        подготовка карты из Natural Earth
internal/data      каталоги и загрузка JSON (defaults/ — значения по умолчанию)
internal/world     тайловая карта
internal/sim       симуляция: экономика, фронт, удары, ПВО, разведка, исследования
internal/netplay   сеть (хост/клиент), песочница, одиночная игра
internal/ai        компьютерный противник (настройки в data/ai.json)
internal/ui        интерфейс на Ebitengine
docs/GDD.md        дизайн-документ
```

Картографические данные: [Natural Earth](https://www.naturalearthdata.com/) (общественное достояние).

## Оформление

Интерфейс в стиле «жидкое стекло» (размытие, преломление, блики). Переключатель — в главном меню или клавиша F9; на слабых видеокартах можно выключить. Шрифт — Inter (лицензия SIL OFL, `internal/ui/fonts/OFL.txt`).

## Настройки экрана
Главное меню → «Настройки» (в партии — Esc → «Настройки»): режим «Окно» / «Полный экран», размер окна (1280×720 … 3840×2160, только помещающиеся на монитор; окно можно и тянуть мышью), масштаб интерфейса «Авто» или 75–200 % шагом 25 %, стиль «стекло» и ползунок его прозрачности. Выбор сохраняется в `settings.json` рядом с игрой. Масштаб, при котором интерфейс не помещается (верхней строке нужно 1440 точек по ширине), недоступен — например, в окне 1600×900 максимум 110 %; в полном экране 1920×1080 — 130 %. Учитывается масштаб Windows (DPI).

## Если игра тормозит (особенно на 4K)
- **Качество отрисовки** (Настройки): «Авто» ограничивает внутренний кадр размером 2560×1440 и растягивает его на экран; 75 % и 50 % ещё легче. Картинка становится чуть мягче, но интерфейс остаётся чётким.
- **F3** показывает FPS, время кадра, память (куча игры, видеопамять под картинки) и графическую библиотеку; скриншот с F3 — лучший способ показать, что происходит.
- **Видеокарта.** На ноутбуках и ПК со встроенной графикой Windows может запускать игру на встроенной: Параметры → Система → Дисплей → Графика → добавить `DroneEbla.exe` → «Высокая производительность».
- `DRONEEBLA_PROF=1` (переменная окружения) пишет `cpu.pprof` и `heap.pprof` рядом с игрой за первую минуту работы.
- `DRONEEBLA_AUDIT=1` печатает в консоль строки, которые не помещаются в рамку, и обрезанные подписи кнопок (для разработчика, вместе со сценариями `DRONEEBLA_SHOT`).
